# Notes batterie

## Tensions mesurees

- Batterie minimale mesuree : `5.65 V`
- Batterie maximale mesuree : `7.8 V`

Cette valeur est une mesure observee sur le robot. Elle ne doit pas etre prise
comme une tension de decharge recommandee : en dessous d'environ `6.0 V`, il
vaut mieux arreter les essais et recharger pour eviter les comportements
instables du robot.

## Reperes rapides

- Pleine charge 2S Li-ion/LiPo : environ `8.4 V`
- Zone basse prudente : environ `6.3 V`
- Minimum observe pendant les tests : `5.65 V`
- Maximum observe pendant les tests : `7.8 V`
